# What Is A Kiosk? 

A Kiosk, or Interactive Kiosk, as paraphrased from kioskindustry.org, is a public facing computer meant to do one of the following things: 
1. Advertise a product.
2. Collect or dispense information.
3. Exchange information, funds, and/or services.

To add to this definition, in an industrial automation standpoint, an HMI (human machine interface) is a special kind of HMI intended to allow an operator to manipulate or control a process.

# Why Use a Kiosk? 

Why would you utilize a Kiosk over a standard desktop environment? There are many reasons: 
1. For security - you don't want a public facing computer to allow a user to access system files or unsavory websites.
2. Purposeful - your public facing computer has one purpose, and should not allow the user to do anything but that purpose.
3. Professionalism - there is an air of professionalism in making a computer appear as utilitarian and purposeful as an appliance. Doing its job and doing it well.
