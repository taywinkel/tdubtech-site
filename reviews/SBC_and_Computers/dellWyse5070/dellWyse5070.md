The Dell Wyse 5070 Thin Client is (or was) utilized in enterprise type systems.

Nowadays, many companies that utilized these thin clients have began to remove them from service. This has flooded second-hand markets like Ebay.com. 

You can get a fully working Dell Wyse 5070 for about $60-$80. Which in my opinion seems quite steep. Why is this? 

While these machines would make a very weak desktop (which cannot run Windows 11, and would probably fail to run Windows 10), it makes a fantastic low budget, low power server! For this, there is actually quite a large market for these! 

There are ways around this however, if you feel adventurous and willing to piece things together yourself...
